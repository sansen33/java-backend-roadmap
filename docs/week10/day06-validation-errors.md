# Week 10 / Day 6 — 验证与错误响应

> 建议用时：60 分钟  
> 今日目标：为错误请求建立稳定、无敏感信息的响应基线。

## 1. 今天学什么

1. 参数校验
2. 错误码
3. 4xx/5xx
4. 日志上下文
5. 敏感信息

## 2. 错误结构

```json
{"code":"EMAIL_CONFLICT","message":"email already exists"}
```

响应不返回堆栈；日志包含足够上下文，但不记录密码和令牌。

## 3. 今天的 60 分钟安排

校验姓名、邮箱和重复邮箱；用真实 HTTP 请求验证错误 JSON。

# 4. Day 6 作业

为三种错误建立稳定响应：无效姓名、无效邮箱、重复邮箱。

## 今日验收标准

- 4xx 与 5xx 区别？
- 为什么不返回堆栈？
- 错误码为何比纯文本稳定？

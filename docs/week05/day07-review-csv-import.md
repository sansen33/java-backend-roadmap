# Week 5 / Day 7 — CSV 导入复盘

> 建议用时：60 分钟  
> 今日目标：完成安全的 CSV 商品导入器。

## 1. 闭卷作业

读取 UTF-8 CSV，跳过表头，校验必填字段和数字，返回有效实体及错误报告。

## 2. 业务规则

1. 每条错误带行号。
2. 无效行不进入结果。
3. 资源自动关闭。
4. IO 异常不吞掉。

## 3. 今日验收标准

- [ ] 正常文件可导入。
- [ ] 空文件、坏数字、缺字段有确定结果。
- [ ] 错误保留 cause。
- [ ] 没有手写脆弱 close。

提交：`git commit -m "complete week 5 exception io"`。

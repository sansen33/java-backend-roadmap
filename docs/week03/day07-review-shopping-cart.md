# Week 3 / Day 7 — 内存购物车复盘

> 建议用时：60 分钟  
> 今日目标：组合 List、Map、Set、Deque 完成内存购物车。

## 1. 闭卷作业

实现商品索引、购物车数量、请求幂等和待结算队列。

## 2. 业务规则

1. 同商品加入数量累加。
2. 重复 requestId 不重复执行。
3. 数量小于等于零拒绝。
4. 删除后不能留下零数量条目。
5. 商品列表排序不能修改源列表。

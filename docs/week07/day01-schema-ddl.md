# Week 7 / Day 1 — 关系模型与 DDL

> 建议用时：60 分钟  
> 今日目标：设计电商基础表及其约束。

## 1. 今天学什么

1. 主键、外键、非空约束
2. 表关系
3. 金额使用 `DECIMAL`
4. 订单项价格快照

## 2. 核心示例

`orders` 保存订单主信息，`order_item` 保存商品、数量和下单时单价。订单项不能只引用商品当前价格。

## 3. 今天的 60 分钟安排

画五表关系图，编写 DDL，插入最小样例。

# 4. Day 1 作业

创建 `user`、`product`、`category`、`orders`、`order_item` 五张表。

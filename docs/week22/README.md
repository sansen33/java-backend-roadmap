# Week 22 — 项目强化

> 每天 60 分钟。目标：为真实高并发场景交付可验证设计。

## Day 1 — 热点缓存
实现互斥重建；验收：重建失败不会污染缓存。

## Day 2 — 缓存穿透
实现短 TTL 空值缓存；验收：不存在 ID 不持续打 DB。

## Day 3 — 重复下单
实现 idempotency key；验收：重试只创建一单。

## Day 4 — 库存一致性
条件更新与事务；验收：库存不为负。

## Day 5 — MQ 幂等
持久化消费记录；验收：重复事件无副作用。

## Day 6 — 设计说明
写故障、权衡、指标与恢复策略。

## Day 7 — 复盘
演练高并发下单；验收：缓存、库存、MQ 三个场景均有证据。

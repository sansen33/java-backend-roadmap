# Week 21 — Spring Cloud

> 每天 60 分钟。目标：构建最小服务发现、调用、网关与限流系统。

## Day 1 — Nacos 注册发现
注册 user/product 服务；验收：实例健康可见。

## Day 2 — 配置中心
外置环境配置；验收：密钥不入仓库。

## Day 3 — OpenFeign
声明式调用与超时；验收：失败可处理。

## Day 4 — Gateway
统一入口与路由；验收：下游不直接公网暴露。

## Day 5 — Sentinel
限流、熔断、降级；验收：降级不伪造成功。

## Day 6 — 链路整合
透传请求 ID；验收：跨服务失败可定位。

## Day 7 — 复盘
交付最小服务系统；验收：注册、调用、网关和限流都经过验证。

# Week 18 — MQ

> 每天 60 分钟。目标：理解异步消息的交付语义与幂等消费。

## Day 1 — Broker 与消息模型
学习 producer、consumer、queue/topic；练习发送订单创建事件；验收：消息体有版本和业务 ID。

## Day 2 — Producer
学习发送确认、超时、重试边界；练习发布 OrderCreated；验收：不以无限重试掩盖故障。

## Day 3 — Consumer 与 ACK
学习手动 ACK、失败处理；练习消费后更新订单；验收：ACK 在成功处理后。

## Day 4 — 重复消费与幂等
学习至少一次交付；练习用 messageId/业务唯一键去重；验收：重复消息不重复扣库存。

## Day 5 — 丢失与堆积
学习持久化、死信、消费积压；练习监控 pending 数量；验收：堆积有扩容/限流策略。

## Day 6 — 延迟消息
学习延迟/定时消息；练习订单超时取消；验收：取消操作幂等。

## Day 7 — 闭卷复盘
实现订单事件生产、幂等消费和失败处理设计。
- [ ] 失败不 ACK。
- [ ] 重复不重复处理。
- [ ] 监控失败/积压。
- [ ] 消息不带敏感数据。

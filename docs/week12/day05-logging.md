# Week 12 / Day 5 — 日志与可观测性

> 建议用时：60 分钟  
> 今日目标：记录可定位问题的结构化日志。

## 1. 今天学什么
- 日志级别、请求 ID、敏感信息边界。

## 2. 实践
为创建用户记录 userId、结果和耗时；不记录密码和令牌。

# 3. Day 5 作业
为异常日志保留 cause 与请求上下文。

## 4. 今日验收标准
- 不以日志替代错误响应。
- 日志可关联一次请求。

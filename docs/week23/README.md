# Week 23 — 面试体系

> 每天 60 分钟。目标：将已完成项目沉淀为准确、可追问的口述答案。

## Day 1 — Java
HashMap、泛型、集合、异常；验收：每题能讲原理与边界。

## Day 2 — 并发与 JVM
线程池、volatile、GC、类加载；验收：用实例解释。

## Day 3 — MySQL
索引、事务、MVCC、锁；验收：能画下单 SQL 链路。

## Day 4 — Redis/MQ
缓存故障、分布式锁、幂等；验收：能说明一致性取舍。

## Day 5 — Spring
IOC、AOP、MVC、事务；验收：不背框架名词。

## Day 6 — 算法与项目
完成题目并复盘项目架构；验收：时间复杂度正确。

## Day 7 — 模拟面试
录音回答并修正模糊表述；验收：每题有结论、证据和边界。

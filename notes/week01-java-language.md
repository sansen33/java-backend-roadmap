# Week 01：Java 语言切换

## 核心概念

### 类型

java中类型校验很严格，变量声明都要在前面定义好类型

#### java 8种基本类型

- byte
- short
- int
- long
- double
- float
- char
- boolean

#### 包装类型

- Integer
- Long
- Double
- Boolean

#### 基础类型和包装类型的区别

- 基础类型直接存储的就是数值，用 == 进行比较
- 包装类型是对象，存储的是对象的引用地址，默认值是null，用.equals进行比较

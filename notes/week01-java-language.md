### 类型

java中类型校验很严格，变量声明都要在前面定义好类型

#### java 8种基本类型

- byte
- short
- int
- long
- double
- float
- char
- boolean

#### 包装类型

- Integer
- Long
- Double
- Boolean

#### 基础类型和包装类型的区别

- 基础类型直接存储的就是数值，用 == 进行比较
- 包装类型是对象，存储的是对象的引用地址，默认值是null，用.equals进行比较


## 访问修饰符
### 常用修饰符
- public 代表其后的数据是公开的，任何地方都能访问
- final 代表其后的数据是最终的，不可修改，不可被继承
- void 表示方法没有返回值

## 构造器
构造器是专门用来创建和初始化
